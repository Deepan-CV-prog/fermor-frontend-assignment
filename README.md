# Fermor — Frontend Developer Assignment

A responsive homepage concept for Fermor, built with **Next.js + React + CSS**.

## Product direction

The homepage is designed around one idea: **financial clarity**. Instead of presenting Fermor as another finance dashboard, the experience leads with a simple promise — understand your money, compare decisions, and know what matters next.

### Included
- Responsive desktop/tablet/mobile layout
- Sticky responsive navigation with mobile menu
- Product dashboard visual built from reusable UI patterns
- Interactive investment growth planner
- Market pulse section
- Functional waitlist form with success state
- Expandable FAQ accordion
- Accessibility-friendly labels and semantic sections
- No external image assets required

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deployment

Recommended: import this repository into Vercel and deploy with the default Next.js settings.

## Design decisions

1. **Calm finance aesthetic:** warm off-white surfaces, deep green typography and restrained accent colors make the product feel trustworthy without looking like a traditional bank.
2. **Product before marketing:** the hero immediately shows what Fermor could feel like in use rather than relying only on claims.
3. **Progressive story:** Understand → Plan → Stay informed → Join.
4. **Working interaction:** the growth planner responds instantly to monthly contribution, time horizon and return assumptions.
5. **Mobile-first behavior:** content collapses into a single readable flow, with a mobile navigation and stacked interactive controls.

## Note

All financial figures in the interface are illustrative UI data for the assignment. The planner is an educational projection and is not financial advice.
